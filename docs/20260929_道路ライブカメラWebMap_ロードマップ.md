# 道路ライブカメラ WebMap ロードマップ

作成日: 2026-09-29  
対象リポジトリ: `onochin/live_camera_view`

## 1. 目的

静岡県東部の道路点検時に、複数管理者が公開している道路ライブカメラを1つのWebMapから確認できるようにする。

特に次の用途を重視する。

- 雨・霧・低雲・積雪・路面状況の事前確認
- 富士山麓、小山町、御殿場、裾野、三島、函南、箱根、伊豆半島の現地調査判断
- 管理者ごとに分散しているライブカメラへのアクセス集約
- 路線番号・路線名・標高・管理者・公式ページを一元管理
- 標高の異なるカメラ映像を比較し、山地の雲底・霧発生高度を推定する補助

> 方針: ライブ映像を自前で再配信するのではなく、各管理者が公開している公式カメラ情報・公式ページへの導線をWebMap上で統合する。

## 4. カメラ台帳のデータモデル

`data/cameras.geojson` を正本とし、1カメラ1Featureで管理する。

### 必須項目候補

| 項目 | 内容 |
|---|---|
| `camera_id` | 一意ID |
| `name` | カメラ名称 |
| `lat` / `lon` | 緯度・経度 |
| `elevation_m` | 標高（m） |
| `manager` | 管理主体 |
| `office` | 土木事務所・河川国道事務所等 |
| `route_no` | 路線番号 |
| `route_name` | 路線名 |
| `area` | 富士山麓、小山、箱根、伊豆等 |
| `municipality` | 市町村 |
| `camera_url` | ライブカメラ表示先 |
| `source_url` | 公式情報ページ |
| `display_type` | 画像直表示 / 公式ページリンク / 動画等 |
| `purpose` | 霧・積雪・路面・河川等 |
| `status` | 有効 / 確認要 / 廃止等 |
| `checked_at` | 最終確認日 |
| `note` | 補足 |

### 標高区分

霧・低雲確認に利用するため、標高を次のように分類できるようにする。

- 500 m未満
- 500～800 m
- 800～1000 m
- 1000～1500 m
- 1500 m以上

## 5. WebMap の主要機能

### Phase 1: 最小構成

- カメラ位置を地図上に表示
- MarkerクリックでPopup表示
- Popupに以下を表示
  - カメラ名称
  - 管理者
  - 路線番号・路線名
  - 標高
  - 市町村・エリア
  - 公式ライブカメラリンク
  - 出典ページ
- 背景地図切替
- 管理者別レイヤON/OFF

### Phase 2: 実務向け検索・絞り込み

- 管理者別フィルタ
- 市町村別フィルタ
- エリア別フィルタ
- 路線番号・路線名検索
- 標高区分フィルタ
- 「現在地周辺」表示（ブラウザ位置情報を使用する場合のみ）

### Phase 3: 霧確認モード

道路点検用の特徴的な機能として実装する。

#### 表示

- カメラを標高別に分類
- 低地→中標高→高標高の順に確認できるUI
- 同一エリアのカメラを一覧表示
- カメラPopupに標高を強調表示

#### 使用例

```text
富士スピードウェイ 約600m
        ↓
須走 約800～1000m
        ↓
水ヶ塚 約1400m
```

例えば、低標高地点は視界良好だが高標高地点が真っ白であれば、その間に雲底が存在する可能性を現地判断の参考にできる。

> 注意: WebMapが自動で「霧あり・なし」を断定するのではなく、現地判断を支援するビューアとして扱う。

### Phase 4: 現地利用の改善

- スマートフォン表示最適化
- よく見るカメラのお気に入り
- 「現場前チェック」用のカメラセット
- カメラを新しいタブで素早く開く
- 更新日時・最終確認日の表示

## 9. QA方針

### データQA

- カメラ位置が道路上または対象施設付近にあること
- 路線番号と路線名が一致すること
- 管理主体が正しいこと
- 公式リンクが有効であること
- 標高値に明らかな異常がないこと

### Web UI QA

基本順序:

1. WSL Playwright / Chromium
2. 必要な場合のみ Windows Chrome
3. スマートフォンは最終段階で実機確認

確認内容:

- 地図初期表示
- Marker表示
- Popup表示
- フィルタ操作
- レイヤON/OFF
- 外部リンク
- コンソールエラー
- モバイル幅の表示
