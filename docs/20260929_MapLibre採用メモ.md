# MapLibre GL JS 採用メモ

作成日: 2026-09-29

## 結論

`live_camera_view` のWebMap実装は、当初ロードマップに記載したLeafletではなく **MapLibre GL JS** を採用する。

## 理由

- 道路ライブカメラ位置の2D表示に対応できる
- WebGLベースで3D地形表示へ自然に拡張できる
- Raster / GeoJSON / Vector Tile / Raster DEMを同一Map上で扱える
- 地理院タイルを背景地図として利用できる
- 将来、静岡県公開DEMや自作Terrain-RGB / PMTiles等へ差し替えやすい
- 富士山麓、箱根、天城等の標高差とカメラ位置を立体的に把握でき、霧確認用途と相性がよい

## v0.1 構成

- MapLibre GL JS 6.11.2
- 背景地図
  - 地理院 淡色地図
  - 地理院 標準地図
  - 地理院 写真
- 3D Terrain
  - Mapterhorn Terrain
  - 全球30m級を初期地形として利用
- カメラ
  - `data/cameras.geojson`
  - 座標確認済み地点から表示

## 3D Terrainの位置づけ

v0.1の3D地形は、道路点検前に次を視覚的に把握することを目的とする。

- カメラ地点と山地・峠の位置関係
- 富士山麓・箱根・伊豆山地の標高差
- 霧確認時に低標高カメラと高標高カメラを比較するための空間的な補助

地形解析精度を目的とするものではない。

## 将来のDEM差替え

候補:

1. 静岡県公開の高解像度DEM
2. 国土地理院標高データをTerrain-RGB等へ変換
3. 自作Terrain-RGB / PMTiles
4. 必要範囲のみ高解像度DEM、それ以外を全球DEMとする構成

高解像度DEMへの差替えは、カメラ台帳・Popup・フィルタ等の機能とは独立して行える構成とする。

## ロードマップ上の読み替え

既存ロードマップ内の「Leaflet」は、今後 **MapLibre GL JS** と読み替える。

Web可視化以降の基本フローは変えない。

```text
公式カメラ調査
  ↓
カメラ台帳
  ↓
GeoJSON
  ↓
MapLibre GL JS WebMap
  ↓
2D / 3D切替
  ↓
検索・フィルタ
  ↓
霧確認モード
```
