# live_camera_view

静岡県東部の道路点検向けに、複数管理者が公開する道路ライブカメラを1つのWebMapから確認するためのビューアです。

## 現在の状態

v0.5（2026-09-30）

- MapLibre GL JS 6.11.2
- 地理院 淡色地図 / 標準地図 / 写真を切替
- Mapterhorn DEMによる3D地形表示
- カメラGeoJSON表示
- 管理者・エリア・文字検索
- カメラPopup
- ローカル利用時は静岡県・国交省の直接画像型カメラをPopup内に表示
- 公開モードでは外部ライブカメラ画像とJPEG直リンクを除外し、公式サイトへのリンクのみ表示
- NEXCO中日本はiHighwayへのリンク地点として表示
- 位置精度を 〇 / □ で区別
- ローカルGeoJSONインポート
- PC / スマートフォン向けレスポンシブ表示

### 国道138号・246号の座標修正

v0.4で、国道138号3地点・国道246号7地点の手作業による概略座標を廃止しました。

- 公開されているPlus Codeを緯度経度へ復元して使用
- 公開ページに記載された標高も付与
- これら10地点は `published_plus_code` として `〇 座標位置` で表示

対象:

- 国道138号: 須走 15.4KP / 16.0KP / 16.9KP
- 国道246号: 生土 89.4KP / 90.0KP / 90.4KP / 中島 91.5KP / 藤曲 93.4KP / 上野 94.8KP / 須川橋 95.6KP

### 凡例

管理者の色:

- オレンジ: 静岡県
- 青: 国交省
- 緑: NEXCO

位置記号:

- `〇`: 座標位置
- `□`: 近傍

`□` は距離標、地名、道路線形、IC・構造物等から配置した代表位置で、カメラ支柱そのものの正確な座標とは限りません。
NEXCOはカメラ支柱位置ではなく、iHighwayを開くための代表リンク地点です。

## 公開モード

v0.5で公開用の安全モードを追加しました。

### 自動切替

- `localhost` / `127.0.0.1`: ローカルモード
  - 直接画像型カメラはPopup内に画像表示
  - 個別画像リンクも利用可能
- `*.github.io`: 公開モード
  - 外部ライブカメラ画像をPopup内へ埋め込まない
  - JPEG等の画像ファイルへの直リンクを公開画面から除外
  - 公式サイト・公式カメラページへのリンクのみ残す

ローカルで公開モードを確認する場合:

```text
http://localhost:8200/?public=1
```

GitHub Pages上でローカルモード相当を確認するための開発用オーバーライド:

```text
?public=0
```

公開時の出典・利用上の注意は `docs/public_notice.html` を参照してください。

## GeoJSONインポート

左側の `GeoJSONインポート` からローカルファイルを選択すると、既存カメラとは別の一時レイヤとして重ねて表示できます。

対応:

- Point / MultiPoint
- LineString / MultiLineString
- Polygon / MultiPolygon
- GeometryCollection
- Feature / FeatureCollection

動作:

- 読み込み後、そのGeoJSONの範囲へ自動ズーム
- Point / Line / Polygonを紫で表示
- クリックでpropertiesを表示
- `クリア`で削除
- ページ再読込でも削除
- ファイル内容はサーバーやGitHubへ送信・保存しない

## 起動

WSL / Ubuntuでリポジトリ直下から:

```bash
python3 -m http.server 8200
```

ブラウザ:

```text
http://localhost:8200/
```

`index.html` を直接 `file://` で開くと、ブラウザの制約によりデータファイルを取得できない場合があるため、HTTPサーバー経由で確認してください。

## 3D地形

v0.5では鍵不要で利用できるMapterhornの全球DEMをMapLibreの `raster-dem` として利用します。

- 目的: 地形とカメラ標高・山地位置関係の把握
- 現状: 全球30m級を基本とするため、詳細地形解析用ではない
- 将来: 静岡県公開DEM、自作Terrain-RGB/PMTiles等への差替えを検討

## 注意

- 本ビューアは道路管理者・情報提供機関の公式サービスではありません。
- 位置情報には、カメラ支柱の正確な座標ではなく、公開されているKP、峠、交差点、構造物等の代表位置を用いる場合があります。
- `□` は近傍・代表位置であることを示します。
- 道路通行時は実際の交通規制・現地状況を優先してください。
