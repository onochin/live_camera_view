# live_camera_view

静岡県東部の道路点検向けに、複数管理者が公開する道路ライブカメラを1つのWebMapから確認するための個人用ビューアです。

## 現在の状態

v0.4（2026-09-30）

- MapLibre GL JS 6.11.2
- 地理院 淡色地図 / 標準地図 / 写真を切替
- Mapterhorn DEMによる3D地形表示
- カメラGeoJSON表示
- 管理者・エリア・文字検索
- カメラPopup
- 静岡県の直接画像型カメラはPopup内に静止画表示
- 国交省の個別JPEGをPopup内に表示
- NEXCO中日本はiHighwayへのリンク地点として表示
- 位置精度を 〇 / □ で区別
- ローカルGeoJSONインポート
- PC / スマートフォン向けレスポンシブ表示

### 凡例

管理者の色:

- オレンジ: 静岡県
- 青: 国交省
- 緑: NEXCO

位置記号:

- `〇`: 座標位置
- `□`: 近傍

`□` は距離標、地名、道路線形、IC・構造物等から配置した代表位置で、カメラ支柱そのものの正確な座標とは限りません。
NEXCOはカメラ支柱位置ではなく、iHighwayを開くための代表リンク地点です。

## GeoJSONインポート

左側の `GeoJSONインポート` からローカルファイルを選択すると、既存カメラとは別の一時レイヤとして重ねて表示できます。

対応:

- Point / MultiPoint
- LineString / MultiLineString
- Polygon / MultiPolygon
- GeometryCollection
- Feature / FeatureCollection

動作:

- 読み込み後、そのGeoJSONの範囲へ自動ズーム
- Point / Line / Polygonを紫で表示
- クリックでpropertiesを表示
- `クリア`で削除
- ページ再読込でも削除
- ファイル内容はサーバーやGitHubへ送信・保存しない

## 起動

WSL / Ubuntuでリポジトリ直下から:

```bash
python3 -m http.server 8200
```

ブラウザ:

```text
http://localhost:8200/
```

`index.html` を直接 `file://` で開くと、ブラウザの制約によりデータファイルを取得できない場合があるため、HTTPサーバー経由で確認してください。

## 3D地形

v0.4では鍵不要で利用できるMapterhornの全球DEMをMapLibreの `raster-dem` として利用します。

- 目的: 地形とカメラ標高・山地位置関係の把握
- 現状: 全球30m級を基本とするため、詳細地形解析用ではない
- 将来: 静岡県公開DEM、自作Terrain-RGB/PMTiles等への差替えを検討

## 注意

- 本ビューアは各機関の公開情報を集約する個人利用向けツールです。
- 位置情報には、カメラ支柱の正確な座標ではなく、公開されているKP、峠、交差点、構造物等の代表位置を用いる場合があります。
- `□` は近傍・代表位置であることを示します。
- 道路通行時は実際の交通規制・現地状況を優先してください。
